Enabling copy and Paste on Linux Mint/Ubuntu on Virtual Box
##########################################################################################

--Make sure you have an optical drive that is empty on Virtual Box for the VM

STEP 1) go to "Devices" > "Insert Guest Additions CD image"

STEP 2) Install the VBoxLinux addtions

sudo ./cdrom/VBoxLinuxAdditions.run

STEP 3) Restart the VM

OR

STEP 1) Start the VM and enter the commands into the command terminal

sudo su
cd /media
mkdir cdrom
mount /dev/cdrom /media/cdrom

STEP 2) Install the VBoxLinux addtions

sudo ./cdrom/VBoxLinuxAdditions.run

STEP 3) Restart the VM

Creating a Shared Folder
###########################################################################################

STEP 1) Go to VM settings in Virtual box and click on 'Shared Folders'

STEP 2) Click the icon to add a shared folder. Enter the location and name of the shared
       folder on the Host machine. Then enter the mount point for the location on the VM

STEP 3) Create a folder of a similar name your home directory

mkdir SharedFolder

STEP 4) turn on the VM (if it is not already on) and add your user to the shared folder
        group,'vboxsf'

sudo adduser ufuoma vboxsf


STEP 5) Reboot the VM (if needed)

-- You can use the 'awk' command for string manipulation. You can use it to select
   words from a text string. it can be used to branch, loop , read from files, print
   out files, do arithmetic

-- The following command passes the output of the 'last' command (prints list of
   last logged in users) to the the 'awk' command (prints the first string in each
   line of output) which in turn passess the output of its command to the 'sort' 
   command which sorts each unqiue value  

last | awk '{print $1}' | sort -u

-- The following takes the contents of the varaible TMPFILE and passes it to the 
   awk command. The awk command takes the input and outputs the first string 
   delimited by ":" followed by a space, then the second string delimited by ":"
   followed by a space, then the 3rd string delimited by a ":". This output is 
   passed to the while loop which read

cat ${TMPFILE} | awk -F: '{print $1 " " $2 " " $3}' | while read TBL DTF BUF
do 
  echo "${TBL} ${DTF} ${BUF}"
done


-- The tee command sends an output both to screen and to an output file. The 
   following example uses the 'tail' command to get the last 10 lines in the alert
   log of a database and sends the output to screen and to the log file specified in
   the tee command

tail -10 alert_${ORACLE_SID}.log | tee last_10_lines.log

-- To allow a script to run even after you disconnect from the shell use nohup, 
   which stands for no-hangup. The following example runs a script (testscript.sh)
   and sends the standard output and standard error output to testscript.out

nohup testscript.sh > testscript.out 2>&1 &

-- The 'cut' command can be used to cut parts of a string. "-d" sets the 
   delimiter. '-f1' means cut field 1 (hello). f2 would be "there"

echo "hello-there" | cut -d '-' -f1

-- The 'paste' command merges the lines from two different files into one line. 
   The first lines in both files will be merged in the output as the first line of
   output

paste file1 file2

-- Use 'sed' command to do a search and replace on an output. the following example

---------------------------File Permissions------------------------------

-- To view a list of permisions for all files use the command below. The
   first entry in each row gives the permissions for the user-group-other 

ls -lh

-- ugo(a) = User / Group / Other / All
-- rwx = Read / Write / Execute

-- To modify permissions use "chmod". Use "+" sign to add persmission and 
   the "-" sign to remove permissions
-- The following command changes the group read and write permissions for 
   the file in the given directory

chmod g+rw <file/dirname>

-- remove read permissions from "Other" for the given file 

chmod o-r <file/dirname>

-- give read and execute permissions to "all"

chmod a+rx <dir/dirname>

-- You can set permissions using numeric or binary representation

numeric: r=4 binary:100
numeric: w=2 binary:010
numeric: x=1 binary:001
numeric: rwx=7 binary:111 (4+2+1)
numeric rw-=6 binary:110

chmod 644 <filename> is equivalent to the following 3 commands 
 chmod u+rw <filename>
 chmod g+r <filename>
 chmod o+r <filename>

OR 

chmod u+rw,g+r,o+r <filename>

-- The number 6 sets the permissions for users, the 4 after the 6 sets 
   permissions for the group, and the lst 4 sets permissions for other


-- To give permission to list a file. 

dir +x

   in the current directory (".") then the "exec" switch allows you to execute a commond (chmod) 
   on the results. after the "find" keyword you can specify the current

   or a full path for any directory
-- It inserts whatever it finds into curly brackets
-- The 755 indicates the permissions on the directory using the numeric method

############################################################################
Redirection
############################################################################

-- Location of terminal error output. "dev" stands for devices. All
   pseudo-files are located in the /dev directory

ls /dev/stderr 

-- Location of terminal input

ls /dev/stdin

-- Location of terminal output

ls /dev/stdout

mail me < my_letter.txt - input operator

---------------------------Redirect Standard output--------------------------------------

-- overwite the file test.txt with the output of the terminal command (stdout)
   instead of displaying the output in the terminal.  

echo "test" > test.txt

-- You can use the numbers 1=stdout, 2=stderr, 3=input in front of the ">" to 
   redirect the output, error output, or input of the terminal into a file. 
   stdout is the default if no number is used in front of the ">" sign

-- the "2>" part sends the error output from the second find command to the 
   /dev/null file. This is a way to dicard error messages that you do not want
   to be displayed in the terminal

find /var/ -name "*.txt" > find 2>/dev/null

-- Use the ampersand (&) symbol to reference a standard channel. The following
   command sends the output of the echo command to channel 2, which is the 
   standard error (stderr) channel which is currently set to the terminal

echo "error" >&2

-- To append an output to the file instead of overwriting it, use ">>"

echo "123" >> test.txt - append operator

-------------------------Redirect Standard input-------------------------------

-- Use "<" to redirect input to someplace else. The example below passes the 
  test.txt file as input to the "wc" command to count the lines ("-l") in the file

wc -l < test.txt

-- You can use "<<" to send input someplace else (i.e sqlplus). "EOF" is an 
   arbitrary marker that signifies the end of the input stream 

sqlplus /nolog << EOF > ${OUTPUT_FILE}

------------------Passing command output to another command-----------

-- The pipe symbol "|" allows you to take the standard output from the 
   preceeding "ls" command to be the input for the following "more" command

ls -lahr /usr/* | more

-- The output of the "du" command is used as an argument in the sort command.
   This entire command can help you find the memory hogs on the system.
   The "h" switch makes the configuration files human readable. The "r" switch
   reverses the order in the sort (largest to smallest). The ouput of the sort
   command is then in turn used as an input for the "more" command

sudo du -hs <directory>/* | sort -hr | more
