--------------------------------- GET database Service name, SID, Hostname ------------------------------------

---- Get the Database name (first 8 characters of the database SID) 

1) SHOW PARAMETER db_name
2) SELECT name FROM V$database;


-- INSTANCE_NAME - 16 character limit name for database instance (AKA set of processes plus memory. In a single-instance database system, 
				  the instance name is usually the same as the database name. the instance name is also the same as the database SID
				  used in naming database service components, windows registry keys, and ORACLE_SID environment variable 
-- SERVICE_NAME - Database service name (SAME as global database name ---> DBname.Domain)
-- TERMINAL - An operating system identifier for the current session. This is often the client machine name.
-- HOST - The host name of the client machine.
-- IP_ADDRESS - The IP address of the client machine.
-- SERVER_HOST - The host name of the server running the database instance.

SELECT SYS_CONTEXT('USERENV','INSTANCE_NAME') FROM dual;
SELECT SYS_CONTEXT('USERENV','SERVICE_NAME') FROM dual;
SELECT SYS_CONTEXT('USERENV','TERMINAL') FROM dual;
SELECT SYS_CONTEXT('USERENV','HOST') FROM dual;
SELECT SYS_CONTEXT('USERENV','IP_ADDRESS') FROM dual;
SELECT SYS_CONTEXT('USERENV','SERVER_HOST') FROM dual;
SELECT SYS_CONTEXT('USERENV','ORACLE_HOME') FROM dual;

EXCLUSIVE: The default value, this setting allows only one instance of one database to use the password file 
SHARED: This setting allows multiple databases running on the same server to use the password file, but it cannot be modified 
NONE: This setting causes Oracle Database to behave as if the password file does not exist

# Configuring different Oracle Home Variables 
############################################################################################

-- Session-Level configuration (settings revert back after exiting the command line)
-- if there are multiple oracle homes within the same host, you will need to configue the
  Oracle environment by setting it up to connect to the correct Oracle home and bin path. The
  bin folder contains the oracle command/binary files for running SQL*Plus, RMAN, expdp, impdp, etc
  
1) SET ORACLE_SID =DBNAME

2) SET ORACLE_HOME='C:\App\Oracle\product\12.2.0\dbhome_1\'

3) SET PATH=%ORACLE_HOME%/bin;%PATH%

3) SET TNS_ADMIN='C:\App\Oracle\product\12.2.0\dbhome_1\network\admin'

OPTION 2 - make ORACLE_SID, ORACLE_HOME variables persistent for all sessions (make permanent) in windows 

You can set you default ORACLE_SID by creating an ORACLE_SID variable in system properties in windows
	- search 'edit environment variables'
	- click on 'New'
	- set varible name to 'ORACLE_SID'
	- set variable value to database name
	
ALTERNATIVE (Allows you to permanently set system variables)
- Go to settings >> system >> About >> Advanced system settings >> Environment Variables

OPTION 3 - make settings permanent using command line for USER ENVIRONMENT (Run as Administrator open new cmd session for changes to take effect) 

-- permanently add a new path to user environment

SETX PATH "C:\Program Files\PostgreSQL\17\bin;%PATH%"

-- Set variable for user environment

SETX ORACLE_SID ORA19C

OPTION 4 - make settings permanent using command line for entrire system


-- Set variable for entire system (In Windows Registry) by adding (/m) at end of command 

SETX ORACLE_SID ORA19C /m

SETX PATH "C:\Program Files\PostgreSQL\17\bin;%PATH%" /m

ORADIM -DELETE -SID TSH1

-- Create a new instance named prod
https://docs.oracle.com/en/database/oracle/oracle-database/19/ntqrf/creating-an-instance-using-oradim.html

C:\> ORADIM -NEW -SID prod -INTPWD password -STARTMODE auto -SRVCSTART system -PFILE C:\app\username\admin\prod\pfile\init.ora

OPTIONS

- SRVCSTART ---> 'system' automatically starts the Oracle database service on reboots
- STARTMODE ----? 'auto' starts the instance when the Oracle database service has started
- INTPWD/SYSPWD ---> sys user password (mininum 8 characters)

---------------------------- CHANGE DATBASE NAME AND SID ------------------------------

oracle DB_NAME has an 8 character limit

https://oracle-base.com/articles/9i/dbnewid#DBNAMEOnly

STEP 1: Shutdown database and start it up in mount mode
STEP 2: use DBNewId utility to set a new database name ONLY or both a new database name and dbid

-- To change both DBID and DBNAME	
	nid TARGET=sys/password@TSH1 DBNAME=TSH2
	
-- to change the DBNAME only
	nid TARGET=sys/password@TSH2 DBNAME=TSH3 SETNAME=YES

STEP 3: change the DB_NAME parameter in the initialization parameter file (in MOUNT mode)
	STARTUP MOUNT
	ALTER SYSTEM SET DB_NAME=TSH2 SCOPE=SPFILE;
	
STEP 4: change the password file name located in ----> ORACLE_HOME\database 
orapwd file=c:\oracle\920\database\pwdTSH2.ora password=password entries=10

STEP 5: rename the SPFILE to SPFILE(NEWDBNAME).ORA located in -----> ORACLE_HOME\database 
STEP 6: In windows delete the Oracle service and recreate it with the new database name

ORADIM -DELETESID -sid TSH1
ORADIM -NEW -SID TSH2 -INTPWD password -SRVCSTART system -STARTMODE a -PFILE ORACLE_HOME\database\spfileTSH2.ora

STEP 7: Alter the listener.ora and tnsnames.ora setting to match the new database name and restart the listener
reload the listener if changes are made to the listener.ora file

STEP 8: Open the database with RESETLOGS (ONLY if the DBID is changed)

STARTUP MOUNT
ALTER DATABASE OPEN RESETLOGS;
