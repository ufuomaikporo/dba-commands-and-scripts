---------------------  STEP 1) Configure Schannel protocols in the Windows Registry

HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\SecurityProviders\SCHANNEL\Protocols 
i) Under 'Protocols' key you can create the TLS 1.2, TLS 1.3 subkeys 
ii) Under 'TLS 1.2' or 'TLS 1.3' subkeys, you can create subkeys 'Client' and/or 'Server'. 
iii) Under 'Client' and 'Server'subkeys, you can create DWORD values 'DisabledByDefault' (Set to 0) 
and 'Enabled' (Set to 1 to enable)

-------------------- STEP 2) Configure security via the Windows Registry

HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\.NETFramework\v2.0.50727

-------------- STEP 3) Configuring TLS Cipher Suite Order by using Group Policy

You can use the SSL Cipher Suite Order Group Policy settings to configure the default TLS cipher suite order.

i) From the Group Policy Management Console, go to Computer Configuration > Administrative Templates > Network > SSL Configuration Settings.

ii) Double-click SSL Cipher Suite Order, and then click the Enabled option.

iii) Click OK or Apply.

......... To change SSL Cipher Suite Order after clicking the Enable option

i) Right-click 'SSL Cipher Suites' box and select Select all from the pop-up menu.

ii) Paste the text into a text editor such as notepad.exe and update with the new cipher suite order list.

iii) Replace the list in the SSL Cipher Suites with the updated ordered list.

iv) Click OK or Apply.

on the server end to ensure encryption. Configure a server certificate (WITH private key) for the 
SQL Server service by giving the service user read permission on the certificate. The certificate should be
under 'personal' certificates in the 'local computer' certificate store and should have a root certificate that

certificate using powershell
