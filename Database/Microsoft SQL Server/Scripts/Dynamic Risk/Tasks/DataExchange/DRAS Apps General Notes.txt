----------------------------------- Database Permissions

----- DataExchangeUser

1. MUST ddl_admin role on the link and stage
2. Must have read and write on the config database
3. Must have EXECUTE on link and stage
4. MUST have read permissions on datbase sources

- Regular User (i.e Dynamic risk users) that are running DataExchange

1. Have ddl_admin role on the link and stage database
2. MUST have read and write on the Stage (tested this with Debra on IRQ) and config databases
3. MUST have EXECUTE on Link and Stage
4. MUST have read permissions on datbase sources

------ For other Apps (Query, AdminTool, RiskAnalyst)

1. Read, Write, and Execute 
2. to publish risk results I usually give (Read, Write, Execute and ddladmin) but I suspect ddladmin might not be necessary

--------------------------------  App Permissions (AdminTools)

- Regular User (i.e Dynamic risk users) that are running DataExchange need to be added and given admin writes
- Users that need to modify templates or overlay files need to be added as an internal user
